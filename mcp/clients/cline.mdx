Cline connects to the SalesCaptain MCP server natively as a remote server. Once connected, Cline can look up and act on your SalesCaptain calls, contacts, messaging, website leads, payments, reviews, and pipeline stages.

```text
https://external-mcp.salescaptain.com/mcp
```

## Before you begin

You need:

- The **Cline** extension installed in VS Code
- A **SalesCaptain** account you can log in to

## Connect Cline

<Steps>
  <Step title="Open MCP servers">
    Open the Cline panel and click the **MCP Servers** icon.
  </Step>
  <Step title="Add a remote server">
    Select **Remote Servers > Add Server**.
  </Step>
  <Step title="Enter the server details">
    Enter a name (`salescaptain`) and the server URL:

    ```text
    https://external-mcp.salescaptain.com/mcp
    ```
  </Step>
</Steps>
