Windsurf connects to the SalesCaptain MCP server through [`mcp-remote`](https://www.npmjs.com/package/mcp-remote). Once connected, Cascade can look up and act on your SalesCaptain calls, contacts, messaging, website leads, payments, reviews, and pipeline stages.

```text
https://external-mcp.salescaptain.com/mcp
```

## Before you begin

You need:

- **Windsurf** installed
- **Node.js**, so `npx` can run `mcp-remote`
- A **SalesCaptain** account you can log in to

## Connect Windsurf

<Steps>
  <Step title="Open Windsurf settings">
    Open Windsurf settings (Cmd/Ctrl + ,).
  </Step>
  <Step title="Find MCP servers">
    Scroll to **Cascade > MCP servers**.
  </Step>
  <Step title="Add a custom server">
    Select **Add Server > Add custom server** and add:

    ```json
    {
      "mcpServers": {
        "salescaptain": {
          "command": "npx",
          "args": ["-y", "mcp-remote", "https://external-mcp.salescaptain.com/mcp"]
        }
      }
    }
    ```
  </Step>
</Steps>
