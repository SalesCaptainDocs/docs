Claude Code connects to the SalesCaptain MCP server natively over HTTP. Once connected, Claude Code can look up and act on your SalesCaptain calls, contacts, messaging, website leads, payments, reviews, and pipeline stages.

```text
https://external-mcp.salescaptain.com/mcp
```

## Before you begin

You need:

- **Claude Code** installed
- A **SalesCaptain** account you can log in to

## Connect Claude Code

<Steps>
  <Step title="Add the server">
    Run this command in your terminal:

    ```bash
    claude mcp add --transport http salescaptain https://external-mcp.salescaptain.com/mcp
    ```
  </Step>
</Steps>
