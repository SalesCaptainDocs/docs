Cursor connects to the SalesCaptain MCP server natively. Once connected, Cursor can look up and act on your SalesCaptain calls, contacts, messaging, website leads, payments, reviews, and pipeline stages.

```text
https://external-mcp.salescaptain.com/mcp
```

## Before you begin

You need:

- **Cursor** installed
- A **SalesCaptain** account you can log in to

## Connect Cursor

<Steps>
  <Step title="Open Cursor settings">
    Open Cursor Settings (Cmd/Ctrl + Shift + J).
  </Step>
  <Step title="Add a server">
    Go to **MCP** and click **Add new MCP server**.
  </Step>
  <Step title="Enter the server URL">
    Select **Type: SSE** and enter the server URL:

    ```text
    https://external-mcp.salescaptain.com/mcp
    ```
  </Step>
</Steps>
