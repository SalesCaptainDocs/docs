VS Code connects to the SalesCaptain MCP server through [`mcp-remote`](https://www.npmjs.com/package/mcp-remote). Once connected, GitHub Copilot can look up and act on your SalesCaptain calls, contacts, messaging, website leads, payments, reviews, and pipeline stages.

```text
https://external-mcp.salescaptain.com/mcp
```

## Before you begin

You need:

- **VS Code** with **GitHub Copilot**
- **Node.js**, so `npx` can run `mcp-remote`
- A **SalesCaptain** account you can log in to

## Connect VS Code

<Steps>
  <Step title="Add the server configuration">
    Add the following to your `.vscode/mcp.json`:

    ```json .vscode/mcp.json
    {
      "mcpServers": {
        "salescaptain": {
          "command": "npx",
          "args": ["-y", "mcp-remote", "https://external-mcp.salescaptain.com/mcp"]
        }
      }
    }
    ```
  </Step>
</Steps>
